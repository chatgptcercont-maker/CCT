# Logo local da Cercont

Coloque a imagem original da marca, no formato PNG, neste diretório com o nome
`cercont.png`. A interface lê esse arquivo localmente, sem conexão com a internet.
Não altere a proporção da imagem. Prefira o arquivo da logo com pouca margem em
volta, para que ela fique legível no cabeçalho.

O arquivo original enviado como imagem no chat ainda não foi disponibilizado no
ambiente de desenvolvimento. Nenhuma logo foi recriada ou apresentada como
original. Enquanto o PNG não estiver presente, o cabeçalho exibe o nome Cercont
em texto. Imagens inválidas não impedem a abertura do monitor.

A paleta da interface foi aproximada visualmente da imagem fornecida: verde
petróleo `#005952`, cinza escuro `#303a37`, fundo claro `#f3f4f3` e branco.
