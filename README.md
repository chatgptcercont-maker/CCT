# Monitor Diário de Convenções e Aditivos — Alagoas

Ferramenta Python para o Departamento Pessoal da Cercont. A interface permite clicar em **Consultar novidades** para pesquisar o Mediador, obter documentos e atualizar uma nova cópia do controle, sem anexos ou arquivo de resultados preparado pelo usuário.

Prepare o ambiente conforme [GUIA_MONITOR.md](GUIA_MONITOR.md) e abra `abrir_monitor.bat` no Windows. Na janela, selecione **Ano de 2026** para o retorno anual ou **Últimos 7 dias** para o acompanhamento recente. O relatório lista todos os instrumentos encontrados, mesmo os já existentes no controle; só os novos são acrescentados à cópia cumulativa. Não há agendamento automático.

A consulta anual real de 01/01/2026 a 09/10/2026 foi concluída: 22 CCTs e 2 aditivos, com os 24 documentos lidos, abrangência em Alagoas confirmada e nenhuma pendência. Inclui quatro registros nacionais SRT. No teste inicial dos últimos sete dias, a pesquisa de aditivos respondeu HTTP 500, registrado como pendência. Consulte o [diagnóstico técnico](DIAGNOSTICO_MEDIADOR.md).

A [alternativa assistida](GUIA_ASSISTIDO.md) permanece disponível. As regras de trabalho e proteção de dados estão em [AGENTS.md](AGENTS.md).
